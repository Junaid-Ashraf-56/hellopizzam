# The Maestro Pizza — ordering website (demo)

Frontend-only food-ordering site for **The Maestro Pizza**, Main Stop, Lahore–Sheikhupura–Faisalabad Rd, near Allied Bank, Chota Manawala, Faisalabad.

A single self-contained `index.html` (no build step). Open it in a browser, or deploy the repo root to GitHub Pages / Vercel / Netlify.

## Features
- Promo strip, header with delivery/pickup address picker, call button, sign-in, live cart count, light/dark toggle
- Hero carousel (auto-advance, pause on hover, arrows, dots, swipe)
- Sticky category bar with scroll highlighting; Veg / Spicy / Favourites filters
- Product cards with favourites and badges; wide deal cards
- Item popup: sizes, crust, extras, deal flavour pickers, instructions, quantity, live total (bottom sheet on mobile)
- Cart drawer with free-delivery progress and "goes well with" suggestions
- Checkout with Pakistani mobile validation (03XX XXXXXXX) and COD / card at door / JazzCash-Easypaisa
- Order confirmation with simulated tracker (preview only — no order is sent)
- Live search, back-to-top, mobile sticky "View cart" bar
- Cart, address, favourites and theme saved in the visitor's browser (localStorage)

## Real vs placeholder
**Real:** name, address, hours (10 am – 3 am daily), Google Maps link.
**Placeholder:** full menu and prices, deals, food images (flat illustrations), phone/WhatsApp, social links, delivery fee (Rs 100, free over Rs 2,000), customer reviews, part of Our Story, sign-in, logo (typographic).
